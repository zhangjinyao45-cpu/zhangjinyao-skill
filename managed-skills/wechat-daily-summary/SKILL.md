# 微信公众号每日读后卡推送

## 架构
```
qbitai.com RSS → Python抓取正文 → AI生成读后卡 → 飞书群(机器人身份)
web_search(新智元) ↗
        ↑
  OpenClaw Cron (每天11:30)
```

## 每日推送流程（Cron 11:30）

### Step 1: 获取文章
1. **量子位** → qbitai.com RSS（Python脚本取当天文章标题+链接+时间戳）
2. **新智元** → web_search 搜索当天AI大新闻
4. **兜底** → 6月30日前未推送过的量子位深度文章

### Step 2: 选文
量子位选1-2篇 + 新智元/兜底选1-2篇（共2-4篇）
（秋芝2046已取消）

### Step 3: 抓取原文
Python urllib 或 web_fetch 抓取原文
- qbitai.com: 带 UA + Referer，否则403
- 新智元: 从搜索到的网页源抓取

### Step 4: 生成读后卡
AI分析原文，按下方模板生成

### Step 5: 发送
`message`工具以机器人身份发送到飞书群，每篇一条消息

⚠️ 严禁使用 `feishu_im_user_message`（用户本人身份），必须用 `message`（龙虾 bot 身份）


### 标题规则
1. 格式：`[读后卡] 【yy.mm】核心主题｜一句话结论`
2. 核心主题：6-12字，名词结构
3. **不使用原文标题**
4. 可复用结论优先写在"｜"后面
5. 【xx.xx】为文章年月

### 标签规则
1. 必须从标签词表中选择（不在词表可创造新标签）
2. 总数3-5个，不加空格，不写句子

**标签词表：**

技术主题（选1）：Agent / Prompt / RAG / 小龙虾 / skills / 预训练 / 强化学习 / sft / 算力 / 评测方法 / 基座模型

类型（选1）：方法论 / 策略 / 案例 / 公司 / 观点 / 框架 / 总结 / 趋势 / 新产品介绍 / 新模型介绍

场景（选2-3）：技巧 / 技术 / ai应用 / 名人观点 / ai pm工作可用 / 高质量材料

### 强约束
- 必须基于原文，不得凭空扩展
- "我的理解"必须是抽象总结，不是复述
- 内容简洁、结构清晰、干货干练
- 每个模块必须填写
- 标题必须符合规则
- **每天每个公众号发1-2篇读后卡**

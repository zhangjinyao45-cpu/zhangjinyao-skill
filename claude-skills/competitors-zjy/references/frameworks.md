# 分析框架模板

供 competitors-zjy 阶段D（框架分析）参考。**按需选用，别硬套全部。** AI PM 日常最常用前三个：定位地图、SWOT、差异化机会。

---

## 1. 竞争定位地图（2x2，最直观、几乎必做）

挑两个**用户最在意**的维度做轴，把我们和竞品都标上去。

**选轴常用组合：**
- 价格（低↔高）× 功能丰富度（轻量↔全面）
- 易用性（小白友好↔专业向）× 专业深度（通用↔垂直）
- 价格 × 目标用户（个人↔企业）

```
            功能全面
               │
   竞品A ●     │     ● 竞品B
               │
低价 ──────────┼────────── 高价
               │
        ● 我们 │   ● 竞品C
               │   （空白象限 ← 机会？）
            轻量简单
```

**关键产出：** 哪个象限是空白的？那里通常就是差异化落点。哪个象限最拥挤？避开或想清楚怎么突围。

---

## 2. 竞品 SWOT

对**我们自己 + 1-2 个最有威胁的竞品**分别做。

| | 正面 | 负面 |
|---|------|------|
| **内部** | **S 优势**：擅长什么、护城河 | **W 劣势**：短板、用户抱怨、功能缺口 |
| **外部** | **O 机会**：利好的市场趋势、未满足需求 | **T 威胁**：监管、技术变革、竞争压力 |

**用法要点：**
- 竞品的 **W**（劣势）和我们的 **O**（机会）常常是同一件事——重点找这种对应
- 对竞品额外加一行「**战略推断**」：综合 SWOT 判断它接下来往哪走（依据招聘/融资/更新日志等信号）

---

## 3. 差异化机会（核心产出，必做）

综合所有调研，回答三个问题：

1. **用户哪些需求还没被满足？**（来自用户口碑里的"求什么功能"和流失信号）
2. **所有竞品的共同短板是什么？**（来自功能矩阵里全员 ⚪/❌ 的行）
3. **我们能在哪个维度做到"明显不同"而非"稍微更好"？**

> 警惕"稍微更好"陷阱：比竞品快 10%、便宜 10%、多一个小功能，都不构成差异化。差异化是让用户**换个角度重新理解这个品类**。

输出 2-3 个候选差异化方向，每个标注：依据（哪些发现支撑）、风险、所需能力。

---

## 4. Porter 五力（可选——判断"这个市场值不值得进"）

适合立项、进入新市场时用；日常对标可跳过。

| 力 | 高=不利（利润薄） | 评估要点 | 应对（若该力高） |
|----|------------------|----------|------------------|
| **竞争激烈度** | 玩家多、增长慢、同质化 | 竞品数量、市场增速、差异化程度、切换成本 | 差异化或成本领先 |
| **新进入者威胁** | 进入门槛低 | 资金/技术/品牌/牌照/网络效应壁垒 | 构建护城河 |
| **替代品威胁** | 替代方案强、切换易 | 有无别的解法、性价比、切换成本 | 加快创新、提高绑定 |
| **买方议价力** | 客户集中、价格敏感、易切换 | 客户集中度、价格敏感度、切换成本 | 提高切换成本、差异化 |
| **供方议价力** | 供应商少、投入独特 | 供应商集中度、可替代性 | 多元供应、纵向整合 |

**结论：** 行业吸引力（高/中/低利润潜力）+ 2-3 句关键动态。

> AI 产品特别注意：底层大模型 API 提供方（OpenAI/Anthropic/国内厂商）往往是强势"供方"，会显著影响这一力。

---

## 5. 护城河（判断优势可持续性）

差异化只是起点，要问"竞品能不能轻易抄走"。可持续优势来自：

| 护城河 | 含义 | AI 产品里的例子 |
|--------|------|----------------|
| **网络效应** | 用户越多价值越大 | 社区/UGC 内容飞轮、协作平台 |
| **切换成本** | 换走代价高 | 数据沉淀、工作流绑定、学习曲线 |
| **品牌** | 认知与信任 | 在垂直场景里"被默认想到" |
| **成本优势** | 规模/自研技术 | 自研模型降本、规模摊薄 |
| **数据/牌照** | 独占数据或资质 | 专有训练数据、合规牌照、专利 |

为差异化方向做体检：它建立了哪种护城河？如果一种都没有，竞品很快会追平。

---

## 6. 蓝海四步法（可选——找全新切入点）

对行业现有竞争要素问四个问题：

| 动作 | 问题 |
|------|------|
| **剔除（Eliminate）** | 行业默认必备、但其实可以拿掉的要素？ |
| **减少（Reduce）** | 哪些要素可以降到行业标准以下？ |
| **提升（Raise）** | 哪些要素该提到行业标准以上？ |
| **创造（Create）** | 行业从未提供、但用户会买单的全新要素？ |

通过"剔除+减少"降成本、"提升+创造"造差异，从而跳出红海正面竞争。

---

## 框架选择速查

| 你的问题 | 推荐框架 |
|----------|----------|
| 我们该往哪个方向做差异化 | 定位地图 + 差异化机会 |
| 这个市场值不值得进 | Porter 五力 + 定位地图 |
| 我们的优势能撑多久 | 护城河体检 |
| 怎么跳出正面竞争 | 蓝海四步法 |
| 某个具体竞品有多大威胁 | 竞品 SWOT + 战略推断 |

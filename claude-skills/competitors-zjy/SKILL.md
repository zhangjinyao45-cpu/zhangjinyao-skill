# 竞品分析ZJY (Competitors-ZJY)

一个为 **AI 产品经理日常竞品分析**蒸馏的中文流程。它把"了解竞争格局"这件事拆成可执行的步骤，最终产出一份**能直接拿去做产品决策**的中文报告，而不是一堆罗列。

蒸馏自三个成熟竞品分析方法：产品/创业向的深度竞品情报（3 波调研 + 作战卡 + 诚实协议）、战略向的经典框架（Porter 五力、SWOT、蓝海四步、定位地图、护城河）、营销向的报告结构。**只保留对 AI PM 日常真正有用的部分**，砍掉 SEO/外链、重型 M&A 情景规划等无关内容。

## 核心理念

> 竞品分析的价值不在"竞品做了什么"，而在"这对我们的产品决策意味着什么"。

三条贯穿全程的原则：

1. **诚实优先（Honesty Protocol）** — 每条关键结论标注来源置信度，区分事实与推测，主动声明数据缺口。宁可写"未找到可靠数据"，也不编造。
2. **决策导向** — 每个发现都要回答"so what"：它指向一个机会、一个风险，还是一个该抄/该避的设计。
3. **轻重可调** — 默认快速版（1-2 小时手动可完成），需要时再升级到深度版。

## 工作流程概览

```
阶段A 锁定范围 → 阶段B 识别竞品 → 阶段C 多维调研 → 阶段D 框架分析 → 阶段E 综合输出
```

**输出文件：** `竞品分析报告-{产品名}.md`（全中文）
深度版可额外拆分出 `竞品作战卡-{竞品名}.md`。

---

## 阶段A：锁定分析范围（Intake）

**目标：** 用 1-2 轮提问把范围问清楚，不做冗长访谈。

**优先复用前置产物。** 如果当前目录或子目录存在 designPM-ZJY 流水线的产物，先读取它们作为起点，避免重复提问：
- `00-需求头脑风暴设计.md` — 产品定义、目标用户、核心功能、已知竞品
- `02-产品需求文档.md` — 功能范围、目标场景

读到后告诉用户："我发现了需求头脑风暴/PRD 的产物，将以它为起点做更深入的竞品分析。"信息足够时直接跳到阶段B。

**若无前置产物，问这些（一次问完）：**
1. 你的产品/想法是什么？解决什么问题、给谁用？（一句话即可）
2. 属于哪个品类/市场？目标地域（国内/海外/特定区域）？
3. 已经知道哪些竞品？（名称、App、网址都行）
4. 这次竞品分析想支撑什么决策？（如：找差异化切入点 / 决定功能优先级 / 定价 / 验证市场是否拥挤）

**别过度提问。** 用户描述清晰就直接进入调研，分析过程自然会暴露关键点。

**输出：** 在报告开头记录一段「分析背景」：产品一句话、品类、目标市场、本次分析要支撑的决策、信息来源（是否基于前置产物）。

---

## 阶段A.5：选择调研深度

根据复杂度给出建议，让用户确认。三个因子各打 1-3 分，求和（3-9）：
- **市场广度**：窄而清晰=1，中等=2，宽泛跨界=3
- **已知竞品数**：明确少数=1，一打左右=2，海量分散=3
- **地域范围**：单一市场=1，多市场=2，全球=3

| 总分 | 档位 | 调研动作 | 适用 |
|------|------|----------|------|
| 3-4 | **快速版** | 3-5 个核心竞品，桌面调研为主，1 份报告 | 日常对标、快速决策 |
| 5-7 | **标准版（默认）** | 5-8 个竞品，含用户口碑挖掘，报告+对比矩阵 | 多数 PM 场景 |
| 8-9 | **深度版** | 8+ 竞品，三波全维度调研，报告+矩阵+定价+作战卡 | 立项、进入新市场 |

告诉用户推荐档位，等待回复（"快速"/"标准"/"深度"/"就按你说的"）后再继续。

---

## 阶段B：识别与分类竞品

把竞品分成三类，避免只盯着明面对手（真正的威胁常来自侧翼）：

| 类别 | 定义 | 例子 |
|------|------|------|
| **直接竞品** | 同样的解法、同样的用户、同样的需求 | 同品类的头部 App |
| **间接竞品** | 不同解法但解决同一个"任务" | 用户当前的替代方案、邻近品类工具 |
| **潜在竞品** | 邻近市场玩家、可能跨界进入的大厂、新晋创业公司 | 平台型大厂的同方向功能 |

**识别方法（AI PM 常用）：**
- 应用商店同类目搜索（App Store / 各安卓市场 / 小程序）+ 看榜单
- 用户在小红书、知乎、即刻、贴吧、微博上"求推荐 XX"的帖子里被提到的产品
- 行业报告、融资新闻（36氪、IT桔子等）里的同赛道玩家
- 搜索"XX 替代品""XX vs""最好用的 XX"
- 问目标用户："你现在用什么解决这个问题？"——挖出真实的间接竞品

**输出：** 一张竞品清单，标注类别、一句话定位、为什么入选。标准/深度版选 5-8 个深入；快速版选 3-5 个。

> 调研原则与数据源质量分级见 [references/research-and-honesty.md](references/research-and-honesty.md)。

---

## 阶段C：多维调研

调研维度按深度档位裁剪。**标准版做前 3 个维度，深度版做全部 5 个。** 每个维度记录证据来源，给关键数据打置信度标签。

### 维度1：竞品画像（必做）
不止看官网/落地页，要交叉验证：
- **产品形态**：核心功能、主要页面、平台（App/Web/小程序/桌面）
- **目标用户**：服务谁、与我们的目标用户重叠度
- **定位与信息**：一句话 slogan、价值主张、品牌调性
- **优势 / 短板**：擅长什么、用户抱怨什么、明显的功能缺口
- **信号**（深度版）：融资轮次、团队规模、招聘方向（招算法=投入 AI、招销售=扩张）、近期更新——用来**推断它的战略走向**

### 维度2：功能对比（必做）
建一张**功能矩阵**：功能为行，"我们 + 各竞品"为列。每格用：✅强 / 🟡一般 / ⚪弱 / ❌无。
重点标出**所有竞品都没做好的功能行**——那是空白机会。

### 维度3：定价对比（标准版起必做）
不止记"多少钱"，要逆向它的定价逻辑：
- 计费模型（按席位 / 按用量 / 订阅 / 一次性 / 免费+增值）
- 各档位怎么拉开差距、卡了哪些关键功能在高档
- 免费策略（免费额度、试用期、是否有水印/限制）
- 切换成本（数据迁移、学习曲线、生态绑定）

### 维度4：用户口碑挖掘（深度版必做，标准版可选）
从真实用户声音里挖"框架问不出来"的洞察：
- **国内**：小红书、知乎、即刻、微博、贴吧、B站评论、应用商店评论
- **海外**：G2、Capterra、Product Hunt、Reddit、App Store
- 提炼：用户**夸什么**、**骂什么**、**求什么功能**；整理一张「用户原话语言地图」（用户描述问题/期望时用的真实措辞，可直接复用到我们的文案）
- 找**流失信号**：用户为什么离开某竞品 → 那就是我们的切入点

### 维度5：GTM 与增长信号（深度版可选）
- 主要获客渠道、内容策略、社媒声量、是否投流
- 增长信号：融资节奏、招聘结构、产品路线图线索（更新日志、公开表态）

> 各维度的调研要点与 AI PM 取数技巧见 [references/research-and-honesty.md](references/research-and-honesty.md)。

---

## 阶段D：框架分析

按需选用，**不要硬套所有框架**。AI PM 日常最常用前三个。

### 1. 竞争定位地图（几乎必做，最直观）
画一张 2x2，挑两个用户最在意的维度做轴（如：价格 低↔高 × 专业度 轻量↔专业，或 易用性 × 功能丰富度）。把我们和各竞品都标上去，找**空白象限**——那通常就是差异化落点。

### 2. 竞品 SWOT
对我们自己 + 1-2 个最有威胁的竞品做 SWOT（优势/劣势/机会/威胁）。竞品的 W 和我们的 O 往往是同一件事。

### 3. 差异化机会（核心产出）
综合前面所有发现，回答：**用户没被满足的需求在哪？所有竞品的共同短板是什么？我们能在哪个维度做到"明显不同"而非"稍微更好"？**

### 4. Porter 五力（可选，判断"这个市场值不值得进"时用）
竞争激烈度 / 新进入者威胁 / 替代品威胁 / 买方议价力 / 供方议价力。适合立项或进入新市场的决策，日常对标可跳过。

### 5. 蓝海四步法（可选，找全新切入点时用）
对行业现有竞争要素问四个问题：**剔除**哪些行业默认要素？**减少**哪些到行业标准以下？**提升**哪些到标准以上？**创造**哪些行业从未提供的？

> 各框架的填写模板与示例见 [references/frameworks.md](references/frameworks.md)。

## 阶段E：综合输出

综合不是把调研结果摆出来，而是**跨维度连点成线**：定价空白 + 某条高频用户抱怨 + 竞品招聘信号 = 一个战略机会。这是整个分析里价值最高的思考，值得多花时间。

按 [references/report-template.md](references/report-template.md) 输出 `竞品分析报告-{产品名}.md`，包含：
1. **分析背景**（产品、市场、本次要支撑的决策、信息来源）
2. **执行摘要**（3 条最关键发现 + 3 条最重要建议，给没空看全文的人）
3. **竞品概览表**（竞品 / 类别 / 定位 / 核心优势 / 威胁等级）
4. **功能对比矩阵**
5. **定价对比**
6. **用户口碑洞察**（夸什么/骂什么/求什么 + 流失信号）
7. **定位地图 + SWOT**
8. **差距与机会**（机会 / 依据 / 优先级）
9. **可落地建议**（建议 / 预期影响 / 实现成本 / 优先级）——AI PM 最该带走的部分
10. **数据缺口与红黄旗**（哪些没查到、哪些信号值得警惕）

**深度版** 额外为每个核心竞品输出 `竞品作战卡-{竞品名}.md`（怎么赢它、什么时候它赢、它的致命短板、它的用户为什么流失），模板见 report-template.md。



## 质量标准（交付前自检）

- [ ] 竞品分了直接/间接/潜在三类，没有只盯明面对手
- [ ] 每条关键结论标了置信度，事实与推测已区分
- [ ] 数据缺口已显式声明，没有用编造填空
- [ ] 功能矩阵标出了"所有竞品都没做好"的空白行
- [ ] 至少有一张定位地图，找到了空白象限
- [ ] 差异化机会是"明显不同"而非"稍微更好"
- [ ] 每条建议都带了优先级和预期影响，PM 能直接据此行动
- [ ] 全文中文，符合中文用户阅读习惯

**核心成功标准：** 这份报告应当让 AI PM **看完就能做决策**——知道该往哪个差异化方向走、哪些功能该优先、哪些坑该避开。
